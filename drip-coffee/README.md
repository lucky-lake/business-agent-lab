# Drip Coffee-오늘의 한 잔

원두 가루 사진으로 분쇄도를 µm 단위로 재고, 문헌 기반 모델로 처음 쓰는 원두의 첫 잔 레시피를 추천합니다. 맛 기록이 쌓일수록 추천이 내 입맛에 맞춰집니다. AI API는 쓰지 않습니다.

배포: https://drip-coffee.streamlit.app/ ('만든 사람 기록 둘러보기'로 체험)

## 목적과 사용자

처음 사는 원두는 맞는 레시피를 찾느라 몇 잔을 맛없게 마시게 됩니다. 저울, 타이머, 휴대폰만 가진 사람이 이 시행착오 없이 새 원두를 즐기도록 돕습니다.

## 사용법

웹은 위 주소, 내 컴퓨터는 `drip-coffee/`에서 `pip install -r requirements.txt` → `streamlit run app.py`. 테스트는 `python -m pytest`입니다.

## 작업 과정

1. 주제(10/6): Claude Code로 계획 4개를 비교해 골랐습니다.
2. 분쇄 분석·모델(10/8–15): 테스트부터 쓰고, 에이전트가 가져온 논문 숫자는 원문과 대조했습니다.
3. 피드백(10/15): 추천 목표를 골든컵에서 내 입맛으로 바꿨습니다.
4. 보정·앱(10/16–24), 모델 고정(10/23), 배포(10/26), 시험(10/28). 자세히: [WORKLOG](docs/WORKLOG.md)

## Claude Code 증거

1. 계획 4개 비교
2. 피드백 뒤 후보 비교
3. 결과 전에 정한 규칙
4. 화면 시안 비교
5. 폰 화면 확인
6. 커밋 전 확인

## 검증

- pytest 테스트 193개 통과
- 처음 보는 원두 4잔 시험: 끊김 4/4, 음료 3/4, 만족도 4/4 통과
- 실패: 음료는 처음 보는 원두 6잔 모두 3–9 g 많게 예측
- 자세히: [MODEL.md](docs/MODEL.md)

## 회고

좋았던 방법
1. 결과 전에 판정 기준을 커밋해, 0.04 g 차이도 불통과로 적었습니다.
2. 화면은 HTML 시안 여러 개를 비교한 뒤 만들었습니다.
3. CLAUDE.md에 규칙을 적고, 커밋마다 내용을 확인했습니다.

어려웠던 점
1. 에이전트가 파일명으로 제 관심사를 추측해, 직접 말하기로 했습니다.
2. 에이전트가 가져온 논문 숫자를 믿을 수 없어 8편을 원문과 대조했습니다.
3. 에이전트가 결과의 원인을 잘못 설명해, 다시 계산해 바로잡았습니다.

## 한계

농도와 추출수율은 추정값이고, 맛 점수는 혼자 블라인드 없이 매겼습니다.

## 핵심 파일

`app.py`(화면), `dripcoffee/`의 `grind_analysis.py`(분쇄), `extraction_model.py`(모델), `calibration.py`(보정), `recommend.py`(추천)
