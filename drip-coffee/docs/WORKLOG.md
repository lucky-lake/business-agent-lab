### 2026-10-04 — 방향 확정: 게임 → 추출 분석·추천 도구 (10/7 기록)
- 결정:
  - 게임은 폐기
  - 문헌 기반 추출 모델 + 사진 분쇄도 측정 + 실제 기록으로 보정 + 목표 농도·추출수율 기반 추천
  - 외부 AI API는 쓰지 않음 (구독과 API 결제가 따로이고, 계산은 코드로 하는 게 정확함)
  - 맛 취향 학습 추천, 가상 시음자는 보류
- 이유: "추출 계산이 좀 더 복잡해지더라도 인터넷이나 학술자료들 모아서 좀 더 재현도가 높은 계산식을 만들어야지"
- 제약: 굴절계 없이 저울·타이머뿐 → 물 빠짐 시간과 음료 무게는 실측으로 보정, 농도·추출수율은 논문 실험 데이터로 검증
- 제안서 제출 (기능 3가지: 분쇄도 측정, 추출 예측·추천, 기록·보정)
- 폐기한 게임 기획은 이력에 남김 (086abfd, 758da46)
