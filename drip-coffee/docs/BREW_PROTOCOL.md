# 측정·촬영 절차

기록이 서로 비교 가능하도록 측정 방법을 고정한다. 바꿔야 하면 바꾼 날짜와 이유를 WORKLOG에 남긴다.

## 장비

- 드리퍼: 하리오 V60, V60 NEO (기록에 어느 것을 썼는지 적는다). **10/12부터 실험 잔은 V60(일반)으로 통일한다.** 드리퍼마다 물 빠지는 속도가 달라서, 섞어 쓰면 흐름 보정이 흔들린다.
- 필터: 본가는 하리오 V60 화이트 02, 기숙사는 홀츠클로츠 무표백(같은 크기). 종이마다 두께와 구멍이 달라 물 빠지는 속도가 다를 수 있으므로, **잔마다 기록의 '필터' 칸에 적는다** (10/19). 10/19 전 기록은 요일로 채웠다(목~일 본가, 월~수 기숙사)
- 그라인더: 홀츠클로츠 메버릭1 (클릭 0~180). 클릭별 크기표(메버릭 클릭표)는 인터넷 기준 값으로, 사진 측정 결과와 비교하는 용도로만 쓴다.
- 저울: 0.1 g 단위
- 주전자: 온도 조절 주전자
- 카메라: 추출 과정 녹화용

## 측정 정의

- **t = 0:** 첫 물이 원두에 닿는 순간
- **붓기 기록:** 각 붓기의 시작 시각(초)과 그때까지 부은 양이 아니라 그 회차에 부은 양(g). 기록 형식은 `시작초:g`를 `;`로 이어 쓴다. 예: `0:40;30:60;60:60;90:60`
- **물 빠짐 종료 시각 (drawdown_end_s):** 드리퍼 끝에서 나오던 물줄기가 끊기고 방울로 바뀌는 순간. 이 순간 **드리퍼를 바로 뺀다.** 영상에서 읽고, 녹화하지 못한 잔은 타이머를 보고 직접 잰다.
- **음료 무게 (beverage_g):** **가수하기 전에** 잰다. 추출 중에 영점을 다시 맞춰도 정확하도록 아래처럼 잰다.
  1. 빈 서버 무게를 한 번 재서 적어 둔다 (서버가 같으면 한 번이면 된다).
  2. 드리퍼를 뺀 뒤 서버를 저울에서 내리고, 빈 저울을 영점에 맞춘다.
  3. 서버를 다시 올려 잰 값에서 빈 서버 무게를 뺀다.
- **가수량 (bypass_g):** 가수한 물의 양. 가수는 농도만 바꾸고 추출수율은 바꾸지 않으므로 따로 적는다.
- **맛 6항목:** **가수한 뒤의 잔** 기준. 0.5 단위. 3점을 보통으로 두고 올리거나 내린다. 아래 '맛 기준'을 따른다.
- **가수 전/후 차이:** 가수 전에 한 모금 먼저 마셔 보고, 가수로 무엇이 달라졌는지 메모에 적는다 (10/12 추가). 예: "쓴맛이 줄었지만 바디가 약해짐"
- **표시 (flag):** 정상이 아닌 잔은 `연습`, `흘림`, `막힘`, `측정실수`, `기타` 중 하나를 적는다. 표시한 잔은 보정에서 뺀다.

## 맛 기준

산미(Acidity)와 바디(Body)는 높다고 좋은 게 아니므로 **세기**로 매긴다. 그래야 분쇄나 추출량과 비교할 수 있다. 나머지 넷은 **만족도**로 매긴다.

| 항목 | 매기는 것 | 범위 | 낮은 점수 | 3점 | 5점 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| Aroma | 마시기 전에 맡는 향의 만족도 | 1~5 | 향이 거의 없거나 불쾌함 (탄내, 눅눅함) | 무난한 커피 향 | 뚜렷하고 좋은 향 |
| Flavor | 머금었을 때 맛과 코로 올라오는 향의 만족도 | 1~5 | 밍밍하거나 쓴맛·탄 맛이 덮음 | 커피다운 맛, 특징은 약함 | 선명하고 풍부함 |
| Acidity | 산미의 세기 | 0~5 | 0 전혀 없음, 1 거의 안 느껴짐 | 적당히 느껴짐 | 아주 강함 |
| Body | 입안의 무게감·질감의 세기 | 0~5 | 0 전혀 없음, 1 물처럼 가벼움 | 저지방 우유 정도 | 진한 우유처럼 묵직함 |
| Balance | 단맛·산미·쓴맛·바디가 어울리는 정도 | 1~5 | 한 가지가 튀어 거슬림 | 대체로 괜찮지만 한쪽으로 치우침 | 잘 어우러짐 |
| Aftertaste | 삼키고 5초쯤 뒤 남는 맛의 만족도 | 1~5 | 금방 사라지거나 떫고 쓴 맛이 남음 | 무난하게 남다 사라짐 | 좋은 맛이 길게 남음 |

맛보는 순서와 규칙:

1. 음료 무게를 잰 뒤, 가수하기 전에 한 모금 마셔 둔다 → 가수 전/후 차이 메모에 쓴다
2. 가수하고 가볍게 섞은 뒤 향을 맡는다 → Aroma
3. 마실 만해지면 한 모금을 입안 전체로 굴린다 → Flavor, Acidity, Body
4. 삼키고 5초쯤 기다린다 → Aftertaste
5. 종합해서 → Balance
6. 점수는 **가수한 직후** 한 번만 매기고, 식으면서 달라진 점은 메모에 적는다. 앞 잔의 점수는 보지 않는다. 마시는 온도가 높을수록 쓴맛이 강하게 느껴지므로(조사 노트 6), 잔마다 비슷한 온도에서 맛보도록 **매번 같은 순서(추출 직후 한 모금 → 가수 → 바로 맛보기)**를 지키고, 가수할 물도 늘 같은 방식(같은 온도)으로 준비한다 (10/15).

쓴맛과 탄 맛은 따로 칸이 없으므로 Flavor·Balance·Aftertaste에 반영하고 메모에 단어로 적는다. 메모에 쓰는 말은 `시큼함`, `밍밍함`(덜 추출된 신호), `떫음`, `쓴맛 강함`, `탄 맛`(과하게 추출된 신호), `단맛 좋음`이다. 덜 추출돼서 나는 불쾌한 신맛은 산미 점수와 따로 `시큼함`으로 적는다.

## 추출 녹화

1. 저울 표시창, 드리퍼, 서버가 한 화면에 보이게 카메라를 고정한다.
2. 녹화를 시작하고, 추출 번호(예: `20261009-1`)를 적은 쪽지를 화면에 잠깐 비춘다.
3. 첫 물을 붓는다(t = 0). 저울 타이머를 함께 켜면 영상에서 시간을 읽기 쉽다.
4. 물줄기가 끊기고 드리퍼를 뺄 때까지 녹화한 뒤 멈춘다.
5. 영상 파일 이름을 추출 번호로 바꾼다. 영상은 저장소에 올리지 않는다.
6. 녹화할 수 없는 날은 타이머를 보고 시각을 직접 재고, 메모에 `영상 없음`이라고 적는다.

## 분쇄 사진

원두와 클릭 설정 조합마다 한 세트를 찍는다. 추출할 때와 같은 원두, 같은 클릭으로 간다.

1. 축척 용지를 '실제 크기(100%)'로 인쇄하고, 기준 막대가 100 mm인지 자로 확인한다(처음 한 번).
2. 추출할 원두를 갈 때 아주 조금을 사진용으로 덜어 둔다. 같은 가루를 찍어야 추출 기록과 분쇄 측정을 짝지을 수 있다.
3. 덜어 둔 가루를 가루 칸에 조금씩 놓고, 카드나 마른 붓으로 **입자 사이가 보일 만큼 듬성듬성** 편다. 가운데 몰리지 않게 칸 전체로 흩고, 칸 테두리와 마커에는 닿지 않게 한다.
4. 카메라나 폰을 종이와 평행하게 들고, 네 모서리 마커가 모두 보이게 찍는다. 플래시는 끄고 그림자 없는 밝은 곳에서 찍는다.
5. **한 장 찍을 때마다 가루를 털어내고 새로 편다.** 같은 입자를 여러 장 찍으면 입자 수만 늘고 정보는 늘지 않는다. 한 클릭 설정마다 모두 합쳐 4~6장 이상 모이게 찍는다.
6. 사진마다 칸(A/B), 렌즈 모드(1배/2배/매크로), 대략의 거리를 `grind_photos.csv`에 적는다. 원본 사진은 저장소에 올리지 않고, 저장소 밖에 추출 번호별 폴더로 모은다.
7. 앱의 '분쇄도 측정' 탭에 같은 가루의 사진을 올려 결과를 확인하고, 원두 번호·클릭 수·추출번호를 넣어 저장한다.

## 뜸 실험 (선택, 시간이 남으면)

**질문:** 뜸 시간이나 뜸 물 양을 바꾸면, 물 빠짐과 음료 무게가 모델이 예측하는 것보다 더 달라지는가?
모델에는 뜸 효과가 없지만, 붓는 시간이 바뀌면서 달라지는 접촉 시간은 계산한다. 그래서 '모델 예측과 실제의 차이'를 보면 접촉 시간과 상관없는 뜸 자체의 효과를 따로 볼 수 있다. 핸드드립의 뜸 효과를 잰 동료 심사 연구는 없다 (조사 노트 5).

원두 B01(디카페인)로 하고, 나머지는 모두 같게 둔다: 원두 20 g, 82 °C, 95클릭, V60, 총 160 g, 가수 130 g.

| 잔 | 바꾸는 것 | 붓기 | 뜸 물 | 뜸 시간 |
| ---- | ---- | ---- | ---- | ---- |
| ① 기준 | — | `0:40;60:80;120:40` | 원두의 2배 (40 g) | 60초 |
| ② 뜸 짧게 | 뜸 시간 | `0:40;30:80;90:40` | 2배 | 30초 |
| ③ 뜸 물 많이 | 뜸 물 양 | `0:60;60:60;120:40` | 3배 (60 g) | 60초 |
| ④ 뜸 없음 | 뜸 생략 | `0:120;60:40` | 없음 (처음에 120 g) | — |

- 평소 기록(물 빠짐 종료, 음료 무게, 맛)에 더해 **첫 방울이 떨어진 시각**을 적는다. 모델은 가루가 물을 다 머금기 전에는 물이 떨어지지 않는다고 가정하는데, 뜸 물 40 g은 머금는 양(약 42 g)보다 적어서 ①②에서는 뜸 동안 거의 떨어지지 않아야 한다.
- 잔마다 모델 예측을 미리 계산해 두고 실제와 비교한다. 차이가 크면 검증 단계에서 '젖는 비율' 항을 넣을지 정한다.
