# 조사 노트 5: 뜸(블룸)

2026-10-15. Claude Code로 문헌을 조사해 정리함. 아래 숫자는 사용자가 원문과 대조하기 전까지 **미확인**이다.

**핵심:** 핸드드립에서 뜸 시간이나 뜸 물 양을 바꿔 추출수율·농도·물 빠짐을 잰 동료 심사 논문은 찾지 못했다. 이산화탄소 양과 빠져나가는 속도는 연구가 탄탄하지만, 뜸 자체의 효과는 블로그 실험이 대부분이다.

## 알려진 것

| 내용 | 값 | 출처 | 상태 |
| ---- | ---- | ---- | ---- |
| 원두에 남은 이산화탄소 (라이트 / 미디엄 / 다크) | 6.3–6.7 / 11.0–11.5 / 15.4–15.6 mg/g | B2 표 4.3 | 미확인 |
| 갈 때 빠져나가는 이산화탄소 (굵게 / 중간 / 곱게) | 26–30 / 33–38 / 45–59 % | B2 | 미확인 |
| 간 가루에서 이산화탄소가 빠지는 시간 규모 | 2–25 시간 | B2 (마른 상태, 25–35 °C) | 미확인 |
| 물에 닿고 공기가 밀려나는 시간 (에스프레소) | 5–10 초 | B5 | 미확인 |
| 물에 닿은 뒤 산 성분(구연산, 사과산)의 절반이 나오는 시간 | 10초 이내 | B6 | 미확인 |
| 가루가 젖을 때 부푸는 정도 | 지름 약 15% (B4) vs 0.5–10분 동안 거의 없음 (B3) | B3, B4 | 서로 다름 |
| 권장 뜸 물 | 원두 무게의 2–3배 | N1, N2, N3 | 블로그 |

- 30–60초 뜸 동안 빠지는 이산화탄소는 남은 양의 일부(수~수십 %)로 추정된다. 마른 상태의 속도로 계산한 조사 단계의 추정이라 뜨거운 물속에서는 다를 수 있다.
- 뜸의 주된 효과는 **가루층 전체를 먼저 적셔서 물이 고르게 흐르게 하는 것**이라는 설명이 많다(N2, N3). 이산화탄소가 흐름을 막는다는 정량 자료는 없다.
- Barista Hustle 실험(N1, 요약만 확인): 뜸 물을 원두의 1·2·4·8배로 늘렸더니 4배까지 물 빠짐이 늦어지고 추출수율이 올랐다. 다만 접촉 시간도 같이 늘어 원인을 나누기 어렵다.
- 뜸을 했든 안 했든 음료에 녹은 탄산 성분의 양은 차이가 없었다(N4, 3회씩).

## 우리 모델에 쓰는 방법

- 지금 모델은 '0초에 모든 가루가 젖는다'고 둔다. 우리 레시피의 뜸은 원두 20 g에 물 40 g(2배)이다.
- 뜸 효과를 넣는다면 '젖은 가루 비율이 5–15초에 걸쳐 올라가고, 젖은 가루만 추출된다'는 항이 가장 단순하다. 시간 값은 문헌에 없어 우리 기록으로 맞춰야 한다.
- 이산화탄소가 흐름을 막는 효과는 근거가 없어 넣지 않는다.
- 뜸 시간(30 / 45초)과 뜸 물(2 / 3배)을 바꾼 실험은 공개된 것이 없어서, 우리가 B01로 직접 재면 새로운 기록이 된다.

## 주의할 점

- 이산화탄소 데이터는 마른 가루를 25–35 °C에서 잰 것이다.
- Barista Hustle 수치는 유료라 원문을 확인하지 못했다.
- 가루가 부푸는 정도는 연구마다 다르다.
- 에스프레소 결과(B5)는 압력이 걸린 흐름이라 핸드드립과 다를 수 있다.
