# 조사 노트 7: 분쇄 사진 분석의 방법과 출처

2026-10-24. Claude Code로 조사해 정리함. 사진 분석 코드(`dripcoffee/grind_analysis.py`)의 단계마다 어떤 방법을 쓰는지 출처를 붙였다.
10/24에 사용자가 링크를 열어 출처 8개(I1–I8)를 모두 확인했다. 앱의 분석 화면에는 사용자가 확인한 출처만 보여 준다.

## 단계별 방법

| 단계 | 코드 | 하는 일 | 출처 | 출처와 관계 |
| ---- | ---- | ---- | ---- | ---- |
| 1. 마커 찾기 | `detect_markers` | 축척 용지의 ArUco 사각 마커를 찾고 꼭짓점을 픽셀보다 정밀하게 잡는다 | I1 | 같은 방법 (OpenCV 구현) |
| 2. 사진 펴기 | `rectify_zone` | 마커 꼭짓점의 실제 위치(mm)와 사진 좌표로 호모그래피를 구해 정면에서 본 모습으로 펴고, 1픽셀이 몇 µm인지 구한다 | I2 | 같은 방법 |
| 3. 조명 고르게 | `flatten_lighting` | 입자보다 큰 원으로 '닫기' 연산을 해 종이 밝기를 추정하고 나눈다 | – | 흔한 배경 보정. 출처를 따로 두지 않음 |
| 4. 입자 재기 | `measure_particles` | 종이와 커피 밝기의 가운데로 입자를 나누고, 칸 테두리에 걸친 입자는 뺀다. 넓이를 같은 넓이의 원 지름으로 바꾼다 | I3 | 비슷함. 정지 이미지로 입자 크기 분포를 재는 표준이지만 본문은 읽지 못함 |
| 5. 붙은 입자 나누기 | `_split_touching` | 거리 지도에서 두꺼운 곳부터 물을 채우듯 넓혀 가며 봉우리마다 입자로 나누고, 두 봉우리 사이 목이 얇으면 따로 둔다 | I6 | 비슷함. 물 채우기(워터셰드) 방식을 따르고, 합치는 기준(NECK_RATIO)은 우리가 정함 |
| 6. 덩어리 빼기 | `_solidity` | 넓이 ÷ 볼록 껍질 넓이(solidity)가 0.75보다 작으면 엉킨 덩어리로 보고 뺀다 | I4 | 같은 지표. 기준값은 우리가 정함 |
| 7. 은피 빼기 | `_count_chaff` | Lab 색공간의 b*(노란 정도)를 종이 색과 비교한다 | – | 사진을 보고 정함. 출처 없음 |
| 8. 대표 크기 | `volume_median` | 지름³으로 가중한 부피 기준 누적 분포의 50% 지점(D50) | I5 | 같은 표현 (부피 기준 분포) |
| 9. 흔들림 범위 | `d50_range` | 잰 입자를 다시 뽑아 D50을 1000번 구하고 5–95% 구간을 낸다 | I7 | 같은 방법 (부트스트랩) |
| 10. 분포 곡선 | `size_distribution_curve` | log 지름 위에서 가우스 커널 밀도로 매끄럽게 그린다 | – | SciPy 구현 |

**앞선 비슷한 도구 (I8):** 흰 종이에 편 가루 사진을 밝기 기준으로 나누고, 붙은 입자를 나누고, 무게 기준 히스토그램을 낸다. 우리 코드는 이 도구를 쓰지 않았고, 축척 마커로 비스듬한 사진도 펴서 축척을 자동으로 구한다.
