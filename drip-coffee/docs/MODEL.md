# 추출 모델 설계 (초안, 2026-10-12)

레시피와 분쇄도로 **물 빠짐 시간, 음료 무게, 농도(TDS), 추출수율(EY)**을 예측하는 모델의 설계다.
식과 상수의 근거는 `docs/research/`의 조사 노트 1–4에 있다. 노트 번호는 `노트1 F2`처럼 적는다.

**상태 표시**
- **미확인:** 문헌에서 가져왔지만 사용자가 아직 원문과 대조하지 않음
- **확인:** 사용자가 원문과 대조함
- **가정:** 문헌에 직접 값이 없어 정한 값. 이유를 함께 적는다.
- **측정:** 우리가 직접 잰 값
- **보정:** 우리 추출 기록에 맞춰 정하는 값

## 1. 무엇을 넣고 무엇이 나오나

| 구분 | 항목 |
| ---- | ---- |
| 입력 | 원두 무게, 붓기 일정(`시작초:g;...`), 주전자 물 온도, 분쇄 측정(앱에 저장한 크기 분포), 가수량 |
| 출력 | 물 빠짐 종료 시각(물줄기가 끊기는 순간), 음료 무게(가수 전), 추출수율, 가수 전·후 농도 |
| 보정 (우리 기록) | 흐름 저항 계수, 가루가 머금는 물 비율. 각각 물 빠짐 시각과 음료 무게에 맞춘다 |
| 검증 (문헌) | 농도와 추출수율. 굴절계가 없어서 문헌 실험값과 비교한다 (노트4) |

## 2. 계산 순서

0.5초 간격으로 시간을 진행하며 아래를 반복한다.

1. **물 붓기:** 붓기 일정대로 드리퍼에 물이 들어온다. 한 번 붓는 동안의 붓는 속도는 입력값이다.
2. **물 흐름:** 드리퍼 안 물에서 가루가 머금는 양을 뺀 나머지가 가루층 위에 고인다. 고인 물의 높이에 따라 아래로 흘러나간다.
3. **추출:** 크기 구간마다 녹아 나온 양을 계산해 드리퍼 안 물에 더한다.
4. **음료:** 흘러나간 물이 그때의 농도만큼 녹은 성분을 함께 가지고 나간다.
5. **종료:** 마지막 붓기가 끝난 뒤 고인 물이 0이 되면 끝난다(물줄기가 끊기는 순간, 드리퍼를 뺌).

## 3. 식

### 3.1 물 흐름 (노트1)

드리퍼 안 액체 무게를 `M_L`, 가루가 머금는 물을 `H = R_abs × 원두 무게`라고 할 때:

```
고인 물      F = max(0, M_L − H)
가루층 부피   V_bed = 원두 무게 / ρ_bulk
물 표면 높이  z = [3·(V_bed + F/ρ) / (π·tan²α)]^(1/3)        (원뿔, 꼭짓점 기준)   … (1)
흘러나가는 양 Q = ρ·g·z / (μ(T)·R)    (F > 0일 때만)                           … (2)
흐름 저항     R = R_ref · (d_ref / d)²                                           … (3)
```

- 식 (2)는 다르시 법칙이다. 물 높이가 높을수록 빨리, 물이 차가울수록(점도가 클수록) 느리게 빠진다.
- 식 (3)은 코제니–카르만 식의 '투과도 ∝ 입자 지름²'을 따른다. d는 사진으로 잰 대표 크기(D50)이고, d_ref = 1000 µm이다.
- R_ref는 **보정 계수 1**이다. 사진이 미분을 놓쳐 절대값 예측은 맞지 않기 때문이다(노트1 주의할 점).
- 종이 필터의 저항은 R_ref에 함께 들어간다. 기록을 보고 따로 떼야 하면 두 번째 계수로 나눈다.

### 3.2 추출 (노트2)

사진으로 잰 크기 구간 i(부피 비율 w_i, 지름 d_i)마다 계산한다. 사진에 안 잡히는 미분은 구간 하나로 따로 넣는다.

```
바로 나오는 비율   φ_i = 1 − (1 − 2δ/d_i)³          (입자 바깥 δ 두께 껍질의 부피 비율)   … (4)
느린 속도          k_i = k_ref · (r_ref / r_i)² · exp[−(Ea/R_gas)·(1/T − 1/T_ref)]           … (5)
녹아 나온 비율     X_i(t) = φ_i + (1 − φ_i)·(1 − e^(−k_i·t))                                 … (6)
녹아 나온 양       M_rel(t) = E_max · 원두 무게 · Σ w_i·X_i(t)                               … (7)
```

- t는 첫 물이 닿은 뒤(뜸 들이기부터) 지난 시간이다. 첫 붓기에서 가루가 모두 젖는다고 본다.
- 식 (5)의 1/r²는 입자 속 확산 시간이 크기의 제곱에 비례한다는 결과다(노트2 K2, K5). 카페인 측정에서도 10% 안쪽으로 맞았다.
- 드리퍼 안 물 온도 T는 `주전자 온도 − ΔT`로 둔다.

### 3.3 음료 (노트3)

```
드리퍼 안 녹은 성분   dS/dt = dM_rel/dt − Q·ρ·S/M_L                    … (8)
음료로 나간 성분     M_d = ∫ Q·ρ·S/M_L dt                              … (9)
음료 무게 (가수 전)   M_bev = ∫ Q·ρ dt                                  … (10)
추출수율             EY = M_d / 원두 무게                              … (11)
농도 (가수 전 / 후)   TDS = M_d / M_bev,   TDS_잔 = M_d / (M_bev + 가수량)   … (12)
```

- 드리퍼 안 물은 고루 섞여 있다고 본다. 가루가 머금은 물에도 같은 농도로 성분이 남아 버려진다.
- 식 (12): 가수는 추출수율을 바꾸지 않고 농도만 낮춘다.

## 5. 보정 (우리 기록 → 계수 2개)

- **R_ref:** `brews.csv`의 물 빠짐 종료 시각(`drawdown_end_s`)과 예측의 차이가 가장 작아지도록 정한다.
- **R_abs:** 음료 무게(`beverage_g`)와 예측의 차이가 가장 작아지도록 정한다.
- `표시`가 있는 잔(연습 등)은 빼고 쓴다.
- 보정 전후의 오차를 비교해 WORKLOG와 검증 문서에 남긴다.
- 기록이 적으면 한 잔을 빼고 나머지로 맞춘 뒤 뺀 잔을 예측해 본다(교차 확인).

## 6. 검증

| 종류 | 내용 |
| ---- | ---- |
| 방향 테스트 | 곱게 갈수록 물이 늦게 빠지고 추출수율이 오르는지. 물이 뜨거울수록 추출수율이 오르는지. 물을 더 부으면 농도는 내리고 추출수율은 오르는지. 원두를 더 넣으면 물이 늦게 빠지는지 |
| 질량 보존 | 부은 물 = 음료 + 가루가 머금은 물 + 녹은 성분 관계가 맞는지. 녹아 나온 양은 E_max를 넘지 않는지 |
| 문헌 비교 1 | Coffee ad Astra V60 (22 g / 374 g / 100 °C): 추출수율 20.8–21.2%, 음료 322–326 g이 비슷하게 나오는지 (노트4) |
| 문헌 비교 2 | Batali 2020: 같은 비율에서 분쇄 1115 → 770 µm, 시간 증가에 따라 추출수율 16–17% → 20–24%로 오르는 크기가 비슷한지 (노트4) |
| 문헌 비교 3 | Váradý 2022 V60: 곱게 갈수록 오르는 방향 (µm가 없어 방향만) |

농도와 추출수율 예측이 문헌과 크게 다르면, k_ref를 노트2의 범위(K5 기준값 ~ K2 카페인 값) 안에서 문헌 데이터에 맞춰 정하고, 그렇게 했다고 밝힌다.

## 7. 알려진 한계

- 속도 상수는 카페인이나 다른 원두에서 왔다. V60, 강배전 값은 없다.
- 온도 영향의 근거가 약하다. 평형에서는 80–99 °C에서 거의 같았다(노트2 K8).
- 사진은 미분을 놓친다. 미분 비율 15%는 다른 그라인더의 값이다.
- 드리퍼 안 물을 고루 섞인 하나의 통으로 보고, 물길 쏠림(채널링)과 미분이 필터를 막는 현상은 넣지 않았다.
- 원뿔 1차원 흐름은 근사다. 실제로는 종이 옆면으로도 물이 빠진다.
